# Source data requirements

Obtain the exact authorized course files and place them in this directory:

- `aisles.csv`
- `departments.csv`
- `order_products.csv`
- `orders.csv`
- `products.csv`

These filenames come from the notebook's local loading code. The supplied package does not identify the exact upstream release or course sampling procedure. No download URL or redistribution license is asserted. A public dataset with a similar name is not a verified substitute.

Raw CSV files are excluded from the repository and ignored by Git. See [execution verification](../../../VERIFICATION.md) for the source-data check.

See the [project README](../README.md#how-to-run) for setup and working-directory instructions.
